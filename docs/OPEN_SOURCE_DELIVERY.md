# 开源交付说明

## 提交内容

1. `software/`：板端完整运行程序、自检程序、单元测试、模型、声音文件和开机自启配置；
2. `fpga/`：Vivado 工程入口、Block Design、RTL、XDC、TCL、IP 配置与最终 BIT/HWH/XSA；
3. `docs/`：B 端最终技术文档；
4. 根目录：README、许可证和 Git 忽略规则。

## 未纳入内容

Vivado 缓存、综合/实现中间产物、仿真临时文件、运行日志、重复采集数据和 Python 缓存未纳入仓库。这些文件不是源码，并可由所附工程和脚本重新生成。

## 版本冻结

- 系统版本：v2.0；
- Overlay 版本寄存器：`0x00020000`；
- 工具链：Vivado 2020.2、PYNQ Ubuntu 20.04；
- 板端目录：`A_bird_system_v2.0_mcp4725_20261102_release`；
- 音频链路：AXI IIC → MCP4725 → PAM8302A → 8 Ω/1 W 喇叭。

## 提交平台要求

- “上传全部代码”应使用本目录制作 RAR，文件小于 200 MB；
- GitHub 仓库应设置为 Public；
- 提交前使用未登录浏览器打开仓库链接，确认无需权限即可访问；
- 不在仓库中加入姓名、学校、账号口令、私钥、令牌和无关个人信息。
